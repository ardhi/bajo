Ecosystem

Ecosystem

Bajo is a modular framework, and its ecosystem is growing rapidly. The following are the main plugins that are part of the Bajo ecosystem. Each plugin has its own documentation and can be installed separately

Bajo Plugins

PackageDocsDescription
bajo-cacheDocsUniversal cache system. Support db result sets and generic caching, in-memory and persistent storage
bajo-cliDocsCommand line interface and tools including project scaffolding, task running, and more
bajo-common-dbDocsCommonly used database and utility functions
bajo-configDocsTOML support, command line converter through applets
bajo-extraDocsExtra utilities and class methods for everyday use
bajo-markdownDocsMarkdown support including parsing, rendering and front matter
bajo-spatialDocsSpatial support including geospatial queries and indexing
bajo-sysinfoDocsSystem information including hardware and software details. Super useful for system diagnostics
bajo-templateDocsOfficial templating engine for Bajo

Dobo DBMS Plugins

PackageDocsDescription
doboDocsDobo DBMS framework. Features include model management, built-in memory adapter, connection manager and more
dobo-extraDocsDobo extra tools and utilities including import/export from/to file with various formats
dobo-couchdbDocsCouchDB adapter for Dobo DBMS
dobo-elasticsearchDocsElasticsearch adapter for Dobo DBMS
dobo-knexDocsKnex based SQL abstraction layer. You must use one of the SQL adapters (e.g., dobo-mysql, dobo-sqlite3, etc) because it doesn't work standalone
dobo-mysqlDocsMySQL/Mariadb adapter for Dobo DBMS
dobo-sqlite3DocsSQLite3 adapter for Dobo DBMS
dobo-postgresqlDocsPostgreSQL/CockroachDB/Redshift adapter for Dobo DBMS
dobo-clickhouseDocsClickHouse adapter for Dobo DBMS
dobo-mongodbDocsMongoDB adapter for Dobo DBMS
dobo-redisDocsRedis adapter for Dobo DBMS
dobo-restproxyDocsRestproxy adapter for Dobo DBMS
dobo-restproxy-jsonserverDocsJsonServer support for doboRestproxy

waibu-extraDocsMost used 3rd party libs including jquery, masonry layout, echarts, highlightjs and more
waibu-mapsDocsWeb maps support based on Maplibrejs offers everything you would need for interactive maps

waibu-phosphorDocsPhosphor Icons support
waibu-rest-apiDocsRest API sub framework offers everything you need to build and serve RESTful APIs
waibu-staticDocsStatic asset management for Waibu framework
waibu-swaggerDocsRest API Documentation support
